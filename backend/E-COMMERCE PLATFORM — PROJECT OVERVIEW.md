E-COMMERCE PLATFORM — PROJECT OVERVIEW

DESCRIPTION
A full-stack e-commerce web application that allows users to browse and purchase products added by admins. The platform supports two user roles — Admin and User — each with dedicated functionality.

ROLES & FEATURES

Admin
- Manage the entire platform: users, products, and categories
- Manage featured products and special offers
- Set and update product pricing and product details
- Add, edit, and delete taglines
- Manage order details, order numbers, and payment status
- Full category management

User
- Browse the product catalog
- View offers and featured products
- Filter products by category and product code
- Add products to cart and place orders
- View order details and history
- Make payments for orders
- Manage profile: update name, email, and address; set a default address

TECH STACK

Backend
- Node.js, Express.js
- MongoDB with Mongoose
- JWT Authentication
- bcrypt (password hashing)
- Role-Based Access Control (RBAC)
- Cloudinary (image/media storage)

Frontend
- React
- TypeScript
- Tailwind CSS
- Fetch API for HTTP requests
